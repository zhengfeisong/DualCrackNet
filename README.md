# Dataset
Road Crack with Disturbance 900 (RCD900) is designed for robust road crack detection under real-world conditions. RCD900 consists of 900 images (resolution: 320 × 320 pixels), normalized to balance visual detail and computational effciency. Collected from the Jiading Campus of Tongji University and various
urban environments, the dataset simulates realistic deployment scenarios for autonomous inspection robots. It features diverse crack morphologies, challenging disturbances (e.g., zebra crossings, traffc markings, road boundaries, natural occlusions), and varying illumination and weather conditions. Each image is annotated with pixel-level segmentation masks
to support supervised learning and quantitative evaluation. The dataset is split into 630 training, 135 validation, and 135 test images.
